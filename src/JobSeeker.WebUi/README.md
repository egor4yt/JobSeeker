# About project

The simplest user interface created for manual API testing

# Use case

On the home page, you will find a "hello-text" and a sidebar. Below the "home" button in the sidebar, you can select from a range of available vacancy options that are supported by JobSeeker.

<img alt="Home page" src="docs%2Fimages%2Fhome-page.png" title="Home page"/>

On the search page, you will find a list of unified vacancies. For each vacancy you can see the time when it got on JobSeeker, an original vacancy title, a short description (processed by JobSeeker) and the name of the company that posted the vacancy.

<img alt="Search page" src="docs%2Fimages%2Fsearch-page.png" title="Search page"/>

On the vacancy page you will find the original title of the position, the company, a description and a list of all original links grouped by job board and location.

<img alt="Vacancy page" src="docs%2Fimages%2Fvacancy-page.png" title="Vacancy page"/>
